Enter any Bitcoin block height to see its date and which Stacks cycle it falls in.

Each reward cycle is 2,100 Bitcoin blocks — a 2,000-block reward phase followed by a 100-block prepare phase. Cycle 0 begins at block 666,050. Past dates are confirmed timestamps from mempool.space; forecasts use the live block interval of the current difficulty epoch.
